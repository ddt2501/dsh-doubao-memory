# 06-SCHEMA · 页面写作规范

每页 3 部分：

1. **顶部 Raw 来源**：`![[RAW/conversations/YYYY-MM-DD]]`
2. **正文 2-3 句精炼洞察**（不是原话，不是流水账）
3. **底部反向链接**：`[[另一页面]]`

**不写**：问候、临时技术状态、闲聊。

## frontmatter 字段

| 字段 | 说明 |
|---|---|
| `类型` | `wiki` |
| `分类` | 所属分类目录名 |
| `主题` | 一句话主题 |
| `状态` | `active` / `dormant` / `archived` |
| `重要度` | 0-1，初始 0.5（lint 每次按半衰期衰减） |
| `创建` / `更新` / `最后强化` | 日期 |
| `强化次数` | 被读到的次数（lint 每次 ×0.5） |
| `生存天数` | TTL（天），到期降级为 `dormant` |
| `遗忘阶段` | 0 新鲜 / 1 观察一期 / 2 观察二期 / 3 待删除 |
| `作用域` | `global` |
| `手改` | `true` ⇒ lint 跳过老化计算 |
