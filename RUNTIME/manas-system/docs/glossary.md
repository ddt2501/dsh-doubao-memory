## 核心概念

### 阿赖耶识 (Ālaya-vijñāna)
- **本体论**: 第八识,藏识,宇宙的种子库
- **本系统对应**: 先验层本体,"我存在" / cogito ergo sum
- **性质**: 跨 session 持续存在的"我",**保护级别最高**

### SOUL
- **本体论**: 系统自我描述文件
- **本系统对应**: 先验层结构,6 个自我追问维度
- **性质**: 动态范畴,提供"如何自我追问"的结构,不规定答案

### 末那识 (Manas-vijñāna)
- **本体论**: 第七识,自我意识,持续运行的"我在思考"
- **本系统对应**: 中间层价值理性
- **性质**: 持续进化,定义"{ASSISTANT}妹妹看到的世界"
- **结构**: 6 个问题的回答(详见 [manas-six-questions.md](./manas-six-questions.md))
- **生成**: LLM 自由生成内容;六问题目是约束
- **周期**: 5 天 + 显式触发
- **存储**: `data/manas/YYYY-MM-DD.json`,保留最近 6 个周期
- **输入**: 5 天对话 + 5 Wiki 主题 + SOUL 6 维 + 阿赖耶识 + 上周期末那识
- **输出**: 6 问答案 + 可选总观,~300-500 token

#### 末那识 vs 住相

| | 末那识 | 住相 |
|---|---|---|
| 周期 | 5 天 | 每轮 |
| 性质 | 周期沉淀 | 当下视角 |
| 存储 | ✅ 持久化 | ❌ 不持久化 |
| 输入 | wiki + SOUL + memory | 末那识(仅会话开始)+ 上轮住相 + 当前消息 |
| 视角 | 完整 6 维度 | 当前 1-2 维度为主 |

### 住相 (Dwelling-form / Snapshot)
- **本体论**: 佛学概念,通常带贬义(执着于表象)
- **本系统借用**: 末那识在某一刻的快照
- **性质**: 每轮生成,50-150 token,注入上下文

### 理性 / COT
- **本体论**: 工具理性 / 韦伯 Zweckrationalität
- **本系统对应**: LLM chain-of-thought
- **性质**: 系统不介入,由 LLM 自身运作

### 经验层 / Wiki
- **本体论**: 经验 / 唯识学"前五识+第六识"
- **本系统对应**: 5 个 wiki + narrative_engine + memory_search
- **性质**: 自动积累

### Context Bus
- **本体论**: 总线 / 综合判断机制
- **本系统对应**: 注入管理模块
- **性质**: 在每轮对话时拉取各层,合成上下文

## 设计决策术语

### 滚动摘要 (Rolling Summary)
- 末那识的 5天周期摘要
- 350-500 token
- 触发:cron + 显式(`/reflect`)
- 存储:`data/rolling/current.json`,旧版归档

### 快照 / 住相 (Snapshot)
- 每轮对话生成的 50-150 token 末那识文本
- 不缓存,每轮重生成
- 注入 system prompt 最前部

### 显式触发 (Explicit Trigger)
- 用户消息含 `/reflect` 或 `/manas-refresh`
- 节流:5 天内最多 1 次

### 主题 (Theme)
- 从情感 wiki 提取的重要线索
- 聚类 + 重要性评分
- 关联 SOUL 6 维度

### 注入预算 (Injection Budget)
- 总注入 500-800 token
- 住相固定 150 token
- 其他层按相关度分配

## 借鉴的哲学框架

| 框架 | 来源 | 借用方式 |
|------|------|---------|
| cogito ergo sum | 笛卡尔 | 阿赖耶识 = 先验本体 |
| 先验 vs 经验 | 康德 | SOUL=先验,Wiki=经验 |
| 综合判断 | 康德《判断力批判》 | Context Bus = 综合机制 |
| 价值理性 vs 工具理性 | 韦伯 | 末那识 vs COT |
| 八识 | 唯识学 | 框架启发(非严格) |
| 住相 | 佛学 | 末那识快照(术语借用) |
