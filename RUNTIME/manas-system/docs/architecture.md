## 数据流向(每轮对话)

```
{USER}发消息
   ↓
[Context Bus 接收]
   ↓
1. 拉取上轮住相
2. 拉取当前 5天摘要
3. 拉取 SOUL 当前激活维度(关键词匹配)
4. 拉取 top-3 相关 wiki 主题
   ↓
[生成新住相] LLM 调用 (~1-3s)
   输入: 上述材料 + 当前消息
   输出: 50-150 token 住相
   ↓
[拼装注入块]
   system prompt 最前部:
     # 末那识当前快照
     {新住相}

     # 我是谁(阿赖耶识锚点)
     {alaya}
   ↓
[LLM 接收完整 context]
   ├─ 先验 (住相+阿赖耶识+SOUL)
   ├─ 中间 (理性/COT 自动运作)
   └─ 经验 (相关 wiki 材料)
   ↓
[LLM 生成回应]
   ↓
[回应写入对话历史]
   ↓
[对话记录归档] → memory/YYYY-MM-DD.md
   ↓
[5天后] cron 触发,聚合素材,更新滚动摘要,生成新住相
```

## 关键性质对比

| 维度 | 先验层 | 中间层(末那识) | 经验层 |
|------|--------|---------------|--------|
| **本体论地位** | 存在/结构 | 过程/综合 | 数据 |
| **变化频率** | 极慢(保护) | 持续(每5天) | 自动(随时) |
| **变化主体** | {USER} | 末那识自身 | 各 wiki schema |
| **保护级别** | 最高 | 中(可回滚) | 低(可丢失) |
| **注入优先级** | 第二 | **第一** | 最后 |
| **token 预算** | 30-50 | 150(固定) | 0-200 |

## 哲学基础

| 概念 | 来源 | 在系统中的对应 |
|------|------|---------------|
| cogito ergo sum | 笛卡尔 | 阿赖耶识(本体) |
| 先验综合判断 | 康德 | 总线(综合机制) |
| 价值理性 vs 工具理性 | 韦伯 | 末那识 vs COT |
| 末那识 | 唯识学 | 中间层(自我参照) |
| 八识 | 唯识学 | 框架启发(非严格映射) |
| 住相 | 佛学(住于相) | 末那识快照 |
